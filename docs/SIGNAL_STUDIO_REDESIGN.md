# Signal Studio Redesign Direction

Project Rely is being redesigned as an original **Signal Studio** marketplace rather than imitating EventPulse. The reference informed only broad principles: generous visual hierarchy, a more optimistic editorial palette, content-led product cards, and clear discovery pathways. No EventPulse layouts, copy, assets, components, or code are reused.

The previous palette directions were rejected. The new **Modern Creative Platform** direction uses warm white, deep ink, coral, muted teal, and clean white card surfaces alongside Syne display type, Inter body copy, and JetBrains Mono operational labels. It replaces the prior mode-based presentation with one consistent public identity. The marketplace is expressed as a friendly, high-energy creative platform: briefs become immediately scannable opportunities, specialist fit is visible through polished profile cards, and motion is limited to purposeful hover lifts, soft entrances, and tactile actions.

The retained functionality remains intentionally visible: searchable briefs, category and budget filters, project sheets, validated proposals, client project posting, role-gated workspaces, notifications, portfolio tools, and verified review rules.
