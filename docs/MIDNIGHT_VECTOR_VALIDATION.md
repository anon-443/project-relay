# Midnight Vector Validation

The initial Signal Studio brights were replaced with a restrained original Midnight Vector visual system: inky graphite surfaces, orchid hierarchy, softened ember actions, sea-glass operational signals, and muted silver content text.

The Web Tactics reference informed only broad design principles: immersive dark atmosphere, decisive display typography, restrained accents, modular structure, and limited motion. Project Rely keeps its own marketplace-specific layout, content, assets, components, and user flows.

At desktop width, the hero, category index, Relay Method, project ledger, specialist directory, workboard, conversation panel, closing section, and footer use a continuous premium dark-surface rhythm. At a 390 px phone viewport, the public navigation, hero, image overlay cards, category index, project ledgers, specialist cards, workboard, and conversation panel remain readable and stack without horizontal overflow.
